# mediflow_backend
 # Mediflow Backend   **AI-Powered Healthcare Referral System API** for African facilities.

##  Features
- Multi-facility referrals w/ real-time tracking
- AI: summaries, quality scores, clinical suggestions
- Voice → transcription → medical notes
- Secure docs (AES-256)
- Role-based auth (Admin/Clinician/Patient)
- Kenya county filtering

##  Quick Start
```bash
git clone https://github.com/yourusername/mediflow_backend
cd mediflow_backend
pip install -r requirements.txt
uvicorn main:app --reload
